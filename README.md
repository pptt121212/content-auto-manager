## 项目概述

**鸭梨AI文章智能写手**是一个功能强大的WordPress插件，基于AI大语言模型技术，为内容创作者、SEO优化人员、网站运营团队提供全自动化的内容生产解决方案。插件通过规则化配置、任务队列调度、向量智能匹配等技术，实现从主题生成到文章发布的全流程自动化，大幅提升内容生产效率，降低运营成本。

### 适用场景

- 🎯 **SEO内容站**：快速覆盖大量长尾关键词，建立内容护城河
- 📰 **新闻媒体**：每日批量产出资讯文章，保持内容更新频率
- 🛍️ **电商平台**：批量生成产品描述、评测、购买指南
- 📚 **知识库/文档**：自动化生成帮助文档、FAQ、教程
- 🌐 **多语言站点**：一键生成多语言版本内容
- 🏢 **多品牌管理**：同时管理多个品牌/网站的内容生产

### 核心优势

1.  **完全开源免费**：基于 GPL v2 协议开源，无任何加密代码，您拥有完全的数据掌控权。
2.  **本地化隐私运行**：核心业务逻辑（任务调度、数据存储、提示词构建）完全运行在您的 WordPress 服务器上，无远程中间层服务器，保障数据隐私与安全。
3.  **零成本大模型支持**：内置 **Pollinations AI** 等免费 API 通道，无需申请 Key 即可免费使用大模型生成高质量文章，大幅降低运营成本。
4.  **免费 SEO 关键词工具**：内置关键词挖掘工具，聚合百度、Google 等搜索引擎下拉推荐词，辅助精准选题。
5.  **规则化海量选题**：通过"主题管理"定义生成规则，一键批量生成成百上千个符合特定领域的主题库，解决选题枯竭问题。
6.  **本地知识库与联网搜索**：
    *   **联网搜索**：提供免费的网络搜索接口，获取最新资讯作为文章素材。
    *   **浏览器插件协同**：(v1.0.8) 独创浏览器插件集成，可调用您本地电脑的 PDF/Word 文档作为知识库，无需上传文件到服务器，让文章内容更准确、更专业。
7.  **独家结构化写作模式**：并非简单的“一键生成”，而是支持 **多提示词模板切换**（如学术风、口语化、SEO 优化版）和 **动态文章结构**（如对比分析、实操指南、案例研究），确保文章逻辑严密、结构清晰，符合 SEO 标准。
8.  **全自动发布流水线**：支持一键批量添加任务，后台自动完成“选题 -> 大纲 -> 撰写 -> 配图 -> 发布”全流程，并支持按照预设时间间隔**定时发布**，实现无人值守运营。
9.  **品牌与 GEO 本地化**：通过“品牌资料库”预设品牌信息（名称、理念、联系方式），并支持在文章中自然融入自定义参考资料（如 GEO 地理信息、促销活动），提升营销转化率。

## 核心功能模块 (Core Function Modules)
*以下功能模块均已通过代码级验证，确保真实有效，非空泛概念。*

### 🎛️ 1. 仪表盘 (Dashboard)
**功能说明**：系统运行状态总览，您的内容生产指挥塔。
**核心价值**：
- 📊 **可视化数据**：实时呈现文章产出量、任务成功率、主题库存。
- ✅ **健康度监控**：快速发现 API 余额不足、任务队列积压等异常。
- 📈 **决策辅助**：基于数据调整生成策略，最大化 ROI。

### 🔌 2. API 设置 (API Settings)
**功能说明**：灵活强大的多模型管理中心。
**支持列表**：
- 🆓 **Pollinations AI (免费大模型)**：无需申请 Key，内置集成，零成本使用 GPT-4 级别模型生成高质量内容。（已验证：`class-pollinations-channel.php`）
- 🌍 **国际巨头**：原生支持 OpenAI (GPT-3.5/4)、Anthropic (Claude 3)、Google Gemini。
- 🇨🇳 **国产之光**：深度适配 阿里通义千问、百度文心一言、智谱 GLM、讯飞星火。
- 🎨 **绘图模型**：支持 DALL-E 3、Midjourney、通义万相、Stable Diffusion。
**独家能力**：
- **混合调度**：支持为"主题生成"使用低成本模型，"文章写作"使用高智能模型，精细化控制成本。
- **自动故障切换**：主 API 如果超时，自动切换备用 API，确保任务不中断。

### 🖼️ 3. 智能配图 (Image Perfection)
**功能说明**：不仅仅是插图，更是视觉营销。
**核心能力**：
- 🎨 **风格定制**：支持设置"写实照片"、"二次元"、"扁平插画"等多种风格提示词模板。
- 📝 **段落级配图**：智能分析段落内容，自动插入与文字高度相关的配图，而非随机插图。
- 🔄 **异步生成**：图片生成不阻塞文章发布，提升并发效率。

### 🔍 4. 免费 SEO 关键词挖掘 (Keyword Research)
**功能说明**：内置的免费 SEO 选题神器。
**数据源**：聚合 **Google**, **Baidu**, **YouTube**, **Bing** 等平台的下拉推荐词。
**使用流程**：
1. 输入种子词（如 "WordPress SEO"）。
2. 一键挖掘 100+ 长尾关键词。
3. 直接将高价值关键词导入"主题库"，作为文章选题。

### 🌐 5. 免费联网搜索 (Network Search)
**功能说明**：让 AI 联网获取最新资讯，拒绝"幻觉"写作。
**工作原理**：
- 🤖 **AI 意图反推**：自动分析主题，反推最佳搜索关键词。
- 🕸️ **Jina Reader 抓取**：自动抓取 Google/Bing 搜索结果的前 10-20 个网页。
- 🧠 **智能清洗**：AI 自动阅读网页，剔除广告和废话，提炼出"高价值事实精华"。
- 📝 **事实注入**：将提炼的最新数据、案例注入到写作提示词中，让文章内容真实可信。

### 📋 6. 规则化选题 (Rule Management)
**功能说明**：内容生产流水线的"总设计师"。
**核心逻辑**：
- 定义**"生成谁"**（目标分类、受众画像）。
- 定义**"怎么生成"**（使用的 API、提示词模板、文章结构）。
- 定义**"生成多少"**（每日生成数量、频率）。
**场景应用**：可以同时创建"每日新闻"（高频短文）和"深度评测"（低频长文）两条流水线并行工作。

### 📑 7. 主题任务（Topic Tasks）
**功能说明**：批量生成文章主题（标题/提纲），建立主题库。

**执行流程**：
```
创建任务 → 选择规则 → 入队调度 → AI生成 → 解析入库 → 完成统计
```

**核心能力**：
- ⚡ 批量生成：一次任务可生成数百个主题
- 🎲 去重机制：向AI提供已有主题列表，避免生成重复主题；支持基于向量和字符相似度的去重判断
- 🔄 自动恢复：失败任务自动重试，支持断点续传
- 📊 进度追踪：实时查看每个子任务的执行状态
- 🔒 并发控制：防止重复创建相同规则的任务

**运营策略**：
- 📅 手动触发：根据需要手动创建主题生成任务
- 🎯 按需生成：热点事件发生时，快速创建紧急任务
- 📈 批次对比：同一规则生成多批主题，对比质量选优

### 📚 8. 主题管理（Topic Management）
**功能说明**：主题库的可视化管理界面。

**核心操作**：
- 🔍 搜索筛选：按分类、规则、状态查询主题
- ✏️ 手动编辑：修改标题、调整分类、删除低质主题
- ➕ 手动添加：导入外部主题或手工创作主题
- 🏷️ 状态管理：标记"未用""已用""已废弃"等状态
- 🎯 向量匹配：为手动主题自动分配最合适的分类

**质量控制**：
- 人工审核：批量预览主题，删除不符合要求的
- 重复检测：通过向量聚类发现相似主题并合并
- 定期清理：删除过时或长期未使用的主题

### 📝 9. 文章任务（Article Tasks）
**功能说明**：将主题扩展为完整文章，发布到WordPress。

**生成能力**：
- 📖 字数控制：800-5000字可配置
- 🎨 结构化内容：支持H2/H3标题、段落、列表、引用等
- 🖼️ 自动配图：调用图像API生成特色图片和内容配图
- 🔗 内链优化：自动插入站内相关文章链接

**发布策略**：
- ✅ **立即发布**：内容生成后直接上线
- 📝 **草稿待审**：先保存草稿，人工审核后发布
- ⏰ **定时发布**：配置发布间隔，按照时间序列定时发布文章

**质量保障**：
- 🎯 人工审核：抽检模式，重点审核高价值内容
- 📊 性能监控：记录生成耗时、成功率、错误类型
- ♻️ 失败重试：API超时或错误自动重试，支持指数退避策略
- 🔍 任务恢复：超时或异常的任务自动检测和恢复

### ⚙️ 10. 发布规则（Publish Rules）
**功能说明**：定义文章发布时的属性配置。

**配置项**：
- 📌 默认状态：发布/草稿/待审核
- 👤 文章作者：指定作者账号
- 📁 默认分类：未指定时的兜底分类
- 🖼️ 配图策略：是否启用自动配图、配图数量、图片提示词模板
- 🎨 文章模板：指定文章结构模板
- 🎯 品牌资料：关联品牌调性
- ⏱️ 发布间隔：设置文章定时发布间隔（分钟）
- 🌐 发布语言：指定内容生成的目标语言

**高级功能**：
- 🔄 自动内链：根据关键词自动插入站内相关文章链接
- 📚 参考资料：启用参考资料功能，丰富文章内容深度
- 🎭 AI角色设定：自定义AI角色描述，控制内容风格

### 🧩 11. 向量聚类（Vector Clustering）
**功能说明**：基于语义向量进行内容聚类和智能推荐。

**核心技术**：
- 🔢 向量嵌入：使用Embedding API将文本转为向量
- 📊 K-Means聚类：自动将相似主题分组
- 🎯 增量更新：新主题自动分配到最近的簇
- 🔍 相似度搜索：快速找到相似内容

**应用场景**：
- 🎯 **自动分类**：手工主题自动匹配到合适分类
- 🔄 **去重检测**：发现重复或高度相似的主题
- 📚 **相关推荐**：在文章底部推荐相似内容
- 📊 **内容分析**：识别网站的内容主题分布

**使用建议**：
- 💾 积累1000+主题后首次训练聚类
- 🔄 每月重新训练一次，保持聚类精度
- 🎯 每100个向量约1个聚类簇（系统自动推荐）

### 🧩 20. 浏览器插件协同 (Browser Extension Integration)
**功能说明**：v1.0.8 核心亮点。打破 Web 端限制，将 WordPress 与您的本地浏览器连接。

**核心价值**：
- 🧠 **本地知识库零上传**：直接读取您本地电脑并在浏览器中打开的文件（PDF, Documentation），利用浏览器算力进行向量检索，保护文档隐私同时降低服务器负载。
- 🔗 **无缝双向通信**：WordPress 在生成文章时，自动向浏览器插件发送检索请求，插件返回精准的上下文片段用于 AI 写作。

**使用流程**：
1. 下载并安装 [鸭梨AI浏览器扩展](https://www.yaliai.com/downs/yali-ai-writer-extension.zip)。
2. 在浏览器扩展中填入本站点的 API Key。
3. 保持浏览器开启，WordPress 后台任务将自动调用本地知识库。

## 安装与配置

### 系统要求

- ✅ WordPress 5.0 或更高版本
- ✅ PHP 7.4 或更高版本
- ✅ MySQL 5.6 或更高版本
- ✅ 至少 256MB PHP 内存限制
- ✅ 支持 WordPress Cron 或系统 Cron
- ✅ 支持 cURL 或 file_get_contents 进行HTTP请求

### 安装步骤

#### 方法一：通过WordPress后台安装
1. 下载插件ZIP压缩包
2. 登录WordPress管理后台
3. 进入"插件" → "安装插件" → "上传插件"
4. 选择下载的ZIP文件并上传
5. 点击"现在安装"
6. 安装完成后点击"启用插件"

#### 方法二：通过FTP上传
1. 解压下载的ZIP压缩包
2. 通过FTP工具连接网站服务器
3. 将解压后的插件文件夹上传到 `/wp-content/plugins/` 目录
4. 登录WordPress管理后台
5. 进入"插件"页面，找到本插件并点击"启用"

### 首次配置

#### 1. 配置AI API（必须）
1. 进入"鸭梨AI写手" → "API设置"
2. 点击"添加自定义API"或选择预定义API
3. 填写API密钥和相关配置
4. 点击"测试连接"确认可用
5. 保存配置

**推荐配置**：
- 🆓 **免费方案**：使用国内免费API试用额度
- 💰 **成本优化方案**：主题生成用便宜模型，文章生成用中端模型
- 🚀 **高质量方案**：全流程使用GPT-4等高端模型

#### 2. 创建生成规则
1. 进入"鸭梨AI写手" → "规则管理"
2. 创建第一条主题生成规则：
   - 规则名称：`每日主题生成`
   - 规则类型：`主题生成`
   - 选择API配置
   - 选择目标分类
   - 设置生成数量：20
3. 创建第一条文章生成规则：
   - 规则名称：`标准文章生成`
   - 规则类型：`文章生成`
   - 选择API配置
   - 配置文章字数：1500-2000字

#### 3. 配置发布规则（可选）
1. 进入"鸭梨AI写手" → "发布规则"
2. 设置默认发布状态（建议先设为"草稿"）
3. 配置作者、分类、标签等
4. 启用自动配图（需先配置图像API）

#### 4. 执行首次任务
1. 进入"鸭梨AI写手" → "主题任务"
2. 点击"创建任务"，选择之前创建的主题规则
3. 等待任务完成（通过仪表盘监控进度）
4. 进入"主题管理"查看生成的主题
5. 选择优质主题，创建文章任务
6. 文章生成完成后，在WordPress后台审核和发布

### 高级配置

#### 启用向量聚类
1. 确保API配置中已设置向量模型
2. 积累至少500个主题
3. 进入"鸭梨AI写手" → "向量聚类"
4. 点击"开始生成/重新校准所有聚类"
5. 等待聚类完成（大量数据需要较长时间）

#### 配置品牌资料
1. 进入"鸭梨AI写手" → "品牌资料"
2. 添加品牌资料，填写详细信息
3. 在发布规则中关联品牌资料
4. 生成内容时将自动注入品牌调性

## 常见问题 (FAQ)

### Q1: 插件生成的文章会被搜索引擎判定为 AI 内容吗？
**A**: 内容质量 > 产生方式。只要文章解答了用户问题、提供了独特价值（如观点、数据、案例），Google/百度 都会收录。建议：
- 使用 **"品牌资料"** 注入独特观点。
- 开启 **"联网搜索"** 获取最新数据。

### Q2: 每天能生成多少篇文章？

### Q3: 免费版功能够用吗？
**A**: **绝对够用！** 免费版包含完整的文章生成、Pollinations AI 免费模型、关键词挖掘工具。仅"浏览器插件协同"和"高级发布规则"等进阶自动化功能需要授权。

## 数据隐私与外部服务说明 (Data Privacy & External Services)

为了符合 WordPress.org 隐私政策与透明度要求，并确保用户对其数据流向有充分知情权，本插件在此明确说明所有涉及外部通信及隐私数据处理的情况：

### 1. 核心业务外部通信 (Core External Communications)

| 服务模型 | 外部服务端点 | 传输数据 | 用途 |
| :--- | :--- | :--- | :--- |
| **授权验证** | 授权服务器 | 域名、授权密钥、插件版本 | 验证高级功能使用权限 |
| **联网搜索(RAG)** | 搜索服务 | 搜索关键词、授权密钥、域名 | 获取实时内容作为写作参考资料 |
| **网页内容解析** | `https://r.jina.ai/` | 目标网页 URL | 将网页转换为适合 AI 阅读的 Markdown 格式 |
| **AI 生成 (LLM)** | 由用户配置（如 OpenAI, Claude, Gemini 等 API 地址） | 提示词、大纲、内容片段 | 驱动 AI 进行内容创作、润色和摘要 |
| **向量生成 (Vector)** | 由用户配置（如 OpenAI Embeddings API） | 文本片段 | 将文本转换为向量以支持深度重复检测和语义搜索 |
| **图片生成** | `https://gen.pollinations.ai` 或用户自定义 API | 绘图提示词 (Prompt) | 为文章自动生成配图 |

### 2. 浏览器插件协同与隐私保护 (Browser Extension & Local Data)

本插件支持与配套的浏览器扩展进行交互，涉及以下场景：

*   **主动抓取 (Active Scraping)**: 当服务器端由于防火墙（如 Cloudflare 等）无法直接访问目标网页时，本插件会向您本地运行的浏览器扩展发送**抓取指令（包含目标 URL）**。扩展在您的浏览器环境物理访问该页面，并将**网页纯文本**回传至插件。
*   **本地知识库 (Local Knowledge Base)**: 扩展可检索您本地存放的 PDF/Word 文档。**插件仅接收检索出的相关文本片段，绝不上传您的原始文件。**
*   **AI 代理网关 (AI Proxy)**: 插件通过本地 REST API (`/wp-json/content-auto-manager/v1/chat/completions`) 为扩展提供 AI 调用中转。这使得您在浏览器扩展中聊天时，可以直接使用该 WordPress 站点配置好的 API Key，而无需在扩展中重复填写。

### 3. 三方工具辅助功能 (Third-party Tools)

*   **关键词研究 (Keyword Research)**:
    *   **联想词挖掘**: 实时连接 `suggestqueries.google.com` (Google) 和 `suggestion.baidu.com` (百度)。
    *   **趋势分析**: 连接 `trends.google.com` 获取关键词热度趋势。
    *   **用途**: 访问这些端点仅为了实时获取搜索建议和流行趋势，不涉及您的站点数据上传。

### 4. 敏感信息保护 (Sensitive Data Protection)

*   **本地存储**: 您的所有 API 密钥（OpenAI Key 等）均经过加密后存储在您本地站点的数据库中，除了发起请求外，绝不经过任何三方服务器（除您配置的服务商外）。
*   **访问拦截**: 插件产生的调试记录和缓存存储在 `logs/` 与 `shared/cache/` 目录下。该目录已内置 `.htaccess` 禁止任何外部浏览器直接读取文件。
*   **隐私申明**: 本插件不会主动收集、存储或出售您的站点内容、用户信息或搜索记录。
