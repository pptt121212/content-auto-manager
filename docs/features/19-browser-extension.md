# 知识库浏览器插件使用说明（Browser Guide & Technical Manual）

## 功能概述
知识库浏览器插件（Content Auto Browser Extension）是插件生态的边缘执行端与能力增强中心。它不仅提供本地知识库的检索，还通过“网站代理（WP Agent Proxy）”模式实现了配置的统一化管理。主要职责包括：
1. **WP Agent 代理引擎**：插件通过 `wordpress-sync` 虚拟驱动连接网站，自动继承网站配置的 LLM 和 Embedding 密钥，无需在扩展端重复输入。
2. **边缘 RAG 执行器**：在“浏览器插件 RAG”模式下，接管复杂的知识检索任务，利用本地 IndexDB 存储和边缘计算能力减轻服务器压力。

## 网站插件配置（准备工作）

### 1. 访问扩展连接页面
进入 WordPress 后台，点击 **“AI SEO 内容管家 > 扩展连接”**。

### 2. 生成 API Key
- 点击 **“🔑 生成 API Key”**。此密钥（X-CAM-API-Key）用于扩展端与 REST API 之间的双向鉴权。
- 复制 **Site URL**。

## 浏览器插件安装与核心设置

### 1. 开启侧边栏 (Side Panel)
插件采用现代 Chrome 侧边栏架构，点击图标后在右侧固定显示，支持在阅读网页时同步操作。

### 2. 连接与代理同步 (Proxy Sync)
- 在侧边栏登录界面填入 **Site URL** 和 **API Key**。
- 点击 **“Connect & Sync”** 后，插件将执行以下逻辑：
  - **安全验证 (Security Guard)**：通过官方服务端验证网站域名的正版授权状态。
  - **虚拟驱动挂载**：挂载 `wordpress-sync` 和 `wordpress-sync-vector` 驱动，后续所有 AI 请求将通过网站中转。

[此处可配图：展示扩展侧边栏成功连接后的“🚀 全托管智能模式已激活”状态]

## 知识库与 RAG 搜索深度使用

### 1. 网页一键爬取
点击扩展顶部的 **“RiGlobeFill (浏览器图标)”**，可将当前浏览的网页内容经过清洗后，一键存入本地知识库（IndexDB）。

### 2. 高级 RAG 搜索流程
在 **Search Panel** 中执行搜索时，插件遵循以下工业级 RAG 流程：
- **查询扩展 (Query Expansion)**：利用 AI 将用户问题自动扩展为多个相关查询词，显著提升召回率。
- **混合检索 (Hybrid Search)**：结合 **向量检索 (Vector)** 与 **关键词匹配 (BM25)**，确保即使在专业术语描述及不精确时也能准确定位。
- **上下文截断**：根据后端模型的 Token 限制，动态计算并截断最相关的知识分片（Chunks）。

### 3. 调试面板 (Search Debug)
点击搜索框下方的 **“RiBugFill (昆虫图标)”** 可开启实时调试。您可以查看到：
- AI 提取的原始关键词。
- 扩展出的查询语句列表。
- 每个知识分片的匹配得分 (Cosine Similarity Score)。

## 自动任务执行与排查

- **轮询机制**：插件每 **5 秒** 自动轮询一次网站的待处理任务（Pending Tasks）。
- **任务确认**：当网站发起“连接验证”时，插件会弹出 Modal 确认窗口。
- **离线处理**：若侧边栏关闭，任务将保持在 Pending 状态。

## 技术实现细节
- **前端架构**：基于 React + Ant Design + Vite。
- **存储方案**：使用 **IndexDB** 持久化本地文本片段与向量索引。
- **通讯类库**：`WPClient` (封装了基于 REST API 的任务获取与结果提交)。
- **任务驱动**：`SearchSection.tsx` 中定义的 `executeWpTask` 自动化链路。

## 常见问题
- **同步失败**：检查网站是否开启了 REST API 访问限制，或是否有防火墙拦截了特定 Header。
- **搜索不到内容**：确认是否在“资源管理”中为对应的 Connection 开启了向量索引构建。
