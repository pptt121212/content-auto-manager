# 核心模块总览

本目录聚焦 Yali AI Writer 主生产链路中最关键的后台页面。它不只是告诉你“这个页面有什么字段”，而是帮助你理解：

1. 这个页面在整套内容生产系统里到底解决什么问题
2. 运营人员应该在什么阶段进入这个页面
3. 页面里哪些区块最值得先看
4. 做完操作后，结果会流向哪里
5. 如果结果不对，应该先回头检查哪个上游模块

---

## 这 8 个核心模块的主链路关系

Yali AI Writer 的核心链路可以先用一句话记住：

**先接入 AI 与搜索能力 → 再设定全局发布标准 → 再定义主题来源 → 再批量生成主题 → 再筛选主题 → 再批量生成文章。**

### 如果你是第一次接手插件

建议按这个顺序读：

1. API 设置
2. 发布规则
3. 规则管理
4. 主题任务
5. 主题管理
6. 文章任务
7. 仪表盘
8. 提示词模板

原因很简单：

- **API 设置**决定系统有没有能力
- **发布规则**决定系统按什么标准产出
- **规则管理**决定主题从哪里来
- **主题任务**负责把规则变成一批主题
- **主题管理**负责把主题整理成可用资产
- **文章任务**负责把主题真正变成文章
- **仪表盘**负责回看全局状态
- **提示词模板**负责更细粒度地校准模型输入

### 如果你是做培训、自动化或 AI 结构化理解

建议按这个顺序读：

## 每个模块分别扮演什么角色

### 1. 仪表盘
是后台总入口，也是运营观察系统状态、统计、缓存和任务健康度的总览页。它不是主生产链路的起点，但能帮你快速判断现在应该去哪个页面处理问题。

### 2. API 设置
是能力接入中心。文本模型、预置渠道、向量模型、搜索服务、Reader 服务都从这里接入。没有这一步，后面的智能流程大多只能空转。

### 3. 发布规则
是全局默认策略中心。文章默认状态、分类方式、目标长度、结构策略、配图、参考资料、品牌资料、语言、角色等都在这里定义。

### 4. 提示词模板
是 Prompt 层的可调节区。它不一定总以一个完整独立页面出现，但实际影响图片提示词、编辑器助手提示词以及部分模型输入模板。

### 5. 规则管理
是主题来源组织器。你在这里定义“系统应该从哪些素材模式中批量生成主题”。

### 6. 主题任务
是主题生产执行页。它负责把规则真正跑起来，生成一批可供后续使用的主题。

### 7. 主题管理
是主题整理中心。主题在这里被筛选、去重、补资料、检查状态，并继续推进到文章生成或深度写作。

### 8. 文章任务
是标准文章生成监控页。它负责展示批量文章任务的进度、失败信息和重试入口。

## 先理解一个关键原则：大多数问题都出在上游

Yali AI Writer 很容易让人产生一种误解：如果文章结果不好，就一定要先去看文章任务页。实际上，很多问题来自更前面的层级：

- API 没配好，生成稳定性就差
- 发布规则没定好，文章风格会飘
- 规则来源不清晰，主题质量就不稳
- 主题筛选没做好，文章任务只是在放大上游问题
- 提示词或结构策略没校准，模型输出就会反复偏移

所以在使用这套系统时，不要把每个页面当成孤立页面来看，而要始终带着“上下游关系”来理解。

## 核心模块的标准业务流

```text
API 设置
  ↓
发布规则
  ↓
提示词模板（按需细化）
  ↓
规则管理
  ↓
主题任务
  ↓
主题管理
  ↓
文章任务
  ↓
WordPress 文章结果
```

仪表盘贯穿整个过程，用来做：

- 总览观察
- 异常排查
- 队列与缓存清理
- 状态分布检查

## 给 AI / 技术读者的结构化摘要

### purpose
建立 Yali AI Writer 核心后台页面的结构化认知，帮助读者理解主生产链路、全局控制层、执行层与监控层之间的关系。

### core modules
dashboard, api settings, publish rules, prompt templates, rule management, topic jobs, topic management, article tasks

### main sequence
api settings → publish rules → optional prompt calibration → rule management → topic jobs → topic management → article tasks

### control layers
- capability layer: API 设置
- policy layer: 发布规则 / 提示词模板
- source layer: 规则管理
- batch generation layer: 主题任务
- curation layer: 主题管理
- execution monitoring layer: 文章任务
- overview layer: 仪表盘

### operator principle
问题优先往上游找，不要只在结果页排查。
