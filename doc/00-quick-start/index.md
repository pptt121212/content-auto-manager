# 快速开始

这个目录不是为了讲完整功能细节，而是为了先帮你建立**正确的学习顺序**。如果你第一次接手 Yali AI Writer，请不要直接跳到某个模块页面去硬看参数，因为这套插件的大多数能力都建立在前后依赖之上。

你在这里会完成三件事。第一，先搞清楚它到底是什么，不要把它误以为只是一个“写文章按钮”。第二，先知道第一次接手时应该按什么顺序推进，避免上来就去调深度写作或结构优化。第三，先把初始化链路走通，为后续的规则、主题、文章和增强模块建立稳定基础。

## 推荐阅读顺序

1. [系统概览：这套插件到底在做什么](01-system-overview.md)
2. [从接手到产出的第一条上手路径](02-first-use-roadmap.md)
3. [安装、接入与初始配置](03-setup-and-initial-configuration.md)

## 这部分读完以后，你应该达到什么状态

读完这一部分之后，你应该已经能回答下面这些问题：

- 为什么这套插件不是单点写作工具，而是一套内容生产系统
- 为什么要先接 API、再定规则、再做主题、再进入文章生成
- 第一次接手时最小可运行链路是什么
- 什么时候可以开始批量出文，什么时候还不应该贸然放量

如果你已经具备这些认知，下一步就进入业务流程文档；如果你还没有把初始化想清楚，先不要跳过这一部分。
