# 发布规则与提示词系统

## 模块用途

发布规则是全局写作策略中心，提示词系统是策略落地到模型输入的执行层。前者决定“文章该怎么生成和怎么发布”，后者负责把主题、结构、资料、语言、图片等信息装配成最终 Prompt。

## 主要子功能

### 1. 全局发布规则

当前页面可配置的主项包括：

- 文章状态
- 发布时间间隔
- 默认作者
- 分类选择模式
- 手动分类与备用分类
- 编辑器 AI 助手开关
- 目标字数
- 内容深度
- 目标受众
- 文章结构指导
- 自动配图
- 内链功能
- 品牌资料植入
- 参考资料功能
- 大模型精选召回
- 素材收集方式
- 搜索意图推断
- 发布语言
- AI 角色描述
- 配图风格模式
- 自动配图提示词

### 2. 分类使用范围

发布规则页面内集成了“分类使用范围”入口。这里决定插件能操作哪些 WordPress 分类，影响规则选择、自动分类和发文归类。

### 3. 结构策略

结构指导有两种主要模式：

- **个性文章结构**：先为当前主题额外生成专属大纲，再据此写文。会多一次 API 调用。
- **通用文章结构**：从文章结构库中按向量相似度匹配现成模板。更适合规模化统一输出。

### 4. 提示词模板系统

仓库里可见的模板类型包括：

- 主题生成模板
- 仿写主题生成模板
- 地域化主题模板
- 文章生成模板
- 仿写文章模板
- 结构生成模板
- 参考资料精选模板
- 图片提示词模板

### 5. 图像提示词系统

支持默认模式，也支持若干预设图片模式。若选择默认模式，还能直接编辑自定义图片提示词模板。

## 用户可以做什么

- 设定全站默认发文规则
- 限定插件可用分类
- 决定文章结构生成方式
- 决定是否启用自动配图、内链、品牌资料和参考召回
- 设定语言和 AI 角色
- 编辑自定义图片提示词
- 打开编辑器 AI 助手，并跳转到助手配置页

## 重要设置

- **category_mode**：决定是手动分类还是根据主题推荐分类自动落类
- **normalize_output**：文章结构指导总开关
- **structure_mode**：个性结构或通用结构
- **auto_image_insertion / max_auto_images / skip_first_image_placeholder**：控制配图数量和位置
- **enable_internal_linking**：依赖向量聚类与相似文章检索
- **enable_brand_profile_insertion**：决定是否从品牌资料库自动植入最相关资料
- **enable_reference_material / enable_ai_reference_select**：决定参考资料召回深度
- **material_collection_mode**：关闭、网络搜索、浏览器知识库搜索
- **publish_language**：影响主题、文章、结构等输出语言
- **role_description**：写作人格和专业角度
- **image_prompt_mode / image_prompt_template**：图片风格与自定义模板

## 数据流转与模块依赖

- 发布规则 → 主题任务  
  搜索意图推断、发布语言等会影响标题生成。

- 发布规则 → 文章任务  
  几乎所有文章生成和发文行为都由这里控制。

- 文章结构管理 → 提示词系统  
  通用结构模式会读取结构库与结构向量。

- 品牌资料 / 搜索物料 → 提示词系统  
  参考资料和品牌资料可进入 Prompt 作为上下文。

- API 设置 → 提示词系统  
  Prompt 拼好后由统一 API 处理器送入实际模型。

- 图像 API → 自动配图  
  文章中只有生成出合法图片占位符后，后续图片链路才会执行。

## 操作注意

- 这是全局默认规则，不是单批任务私有配置。修改后会影响后续所有任务。
- 个性结构和大模型精选召回都会增加一次额外模型调用。
- 自动配图不是只勾开关就行，还要确认图像 API 已配置。
- 通用结构依赖文章结构库，结构库为空时效果会明显退化。
- 内链效果依赖向量和聚类结果，没做向量治理时不要对结果期待过高。
- 自定义图片提示词必须输出标准图片占位符格式，否则系统无法替换成图片。

## 什么时候使用

- 你要先把全局写作和发布策略定下来时
- 你准备批量生产一批统一风格文章时
- 你要切换语言、受众、结构方式或资料召回策略时
- 你发现文章质量波动，需要从 Prompt 与规则层做校准时
