# 主题管理

## 模块用途

主题管理是“主题产出后的整理中心”。它负责承接主题任务生成出的主题，供用户筛选、去重、补资料、检查向量状态，并把合适主题继续送入文章任务。

## 主要子功能

### 1. 主题列表与状态管理

当前可见主题状态包括：

- 未使用
- 队列中
- 已使用

### 2. 高级筛选

页面支持按以下条件筛选主题：

- 任务 ID
- 标题关键词
- 状态
- 推荐分类
- 优先级
- 是否已生成向量
- 是否已有参考资料

### 3. 重复标题检测

主题管理内置重复检测，可检测：

- 完全相同标题
- 向量相似度高于阈值的近似重复主题

### 4. 参考资料与向量状态检查

页面已显式区分：

- 是否有参考资料
- 是否已生成向量

## 用户可以做什么

- 按条件筛选主题
- 搜索指定任务生成的主题
- 检查推荐分类是否合理
- 检查主题是否已有参考资料
- 检查主题是否已生成向量
- 做重复标题检测
- 清理重复主题
- 从可用主题继续推进到文章任务

## 重要设置

- **状态筛选**：用于区分可继续生产的主题
- **推荐分类**：会影响自动分类落点
- **优先级分数**：适合做人工挑选和批次排序
- **向量状态**：会影响相似度判断、结构匹配、品牌/参考召回
- **参考资料状态**：会影响文章提示词的信息密度

## 数据流转与模块依赖

- 主题任务 → 主题管理  
  主题任务生成的主题先落库，再进入主题管理列表。

- 主题管理 → 文章任务  
  被选中的主题会进入文章任务，生成正式文章。

- 主题管理 → 向量服务  
  主题表里会记录 `vector_embedding` 等字段，供相似度、聚类和结构选择使用。

- 搜索物料 / 品牌资料 → 主题管理  
  主题的 `reference_material` 可能来自搜索物料结果，或在启用参考资料功能时由品牌资料召回补足。

- 发布规则 → 主题管理  
  自动分类、搜索意图推断、发布语言等上游设置都会影响主题生成结果。

## 操作注意

- 没有向量的主题，很多智能能力只能退化运行，尤其是去重、结构匹配和召回。
- 主题已经进入文章队列后，不适合再做大范围内容改写。
- 重复检测阈值不要设得过低，否则会误删语义接近但仍可独立成文的主题。
- “有参考资料”不等于资料质量高，关键主题最好人工抽查。

## 什么时候使用

- 主题任务刚跑完，需要做人工筛选时
- 你想清理重复主题时
- 你想确认哪些主题具备进入文章生成的条件时
- 你要从主题池里挑一批主题进入文章任务时
