# 支撑能力

## 模块用途

这些模块不是主生产链路的起点，但会明显影响文章质量、资料密度、品牌一致性、SEO 判断和后续智能能力。它们通常作为发布规则和文章任务的增强层出现。

## 1. 编辑器助手

### 作用
为 WordPress 编辑器提供快捷 AI 操作，不只服务自动写作，也服务人工改稿。

### 主要能力
- 文本生成提示词管理
- 图像生成提示词管理
- REST 接口生成内容
- 依据选中文本替换占位符
- 自动保持输出语言与原文一致

### 与主流程的关系
- 开关在“发布规则”里
- 提示词内容在“编辑器助手配置”里维护
- 实际生成走统一 API 处理器

## 2. 图片能力

### 作用
让文章自动配图真正落地，不只是输出占位符。

### 主要能力
- 图像 API 提供商配置
- 多提供商支持
- 自动配图提示词模式
- 文章内图片占位符替换

## 3. 品牌资料

### 作用
沉淀品牌文案、卡片、图片和内部参考资料，供文章自动植入或作为知识参考。

### 主要能力
- 标准样式资料
- 自定义 HTML 资料
- 参考资料型资料
- 相似度匹配后自动植入或召回

## 4. 搜索物料

### 作用
在主题已有标题的前提下，补充联网资料或知识库资料，丰富文章上下文。

### 主要能力
- 网络搜索模式
- 浏览器知识库搜索模式
- 搜索、筛选、抓取、汇总
- 保存为主题参考资料

## 5. 关键词研究

### 作用
做上游关键词发现，不直接写文，但能帮你扩充选题池和备用词库。

### 主要能力
- 基础关键词挖掘
- 多地区选择
- 多数据源选择
- 深度挖掘
- 结果勾选、复制、清空

## 6. GSC 流量洞察

### 作用
把 Google Search Console 数据引入内容决策，帮助你找到值得补内容的词和页面。

### 主要能力
- Google 账户授权
- 站点选择
- 查询词表现
- 页面表现
- 智能词包推荐
- AI 效果追踪
- 排除关键词设置

## 7. 文章结构

### 作用
维护结构模板库，让文章生成更稳，更适合批量化。

### 主要能力
- 按内容角度管理结构
- 结构模板查看与维护
- 结构智能优化
- 与主题向量做相似匹配

## 8. 向量与聚类

### 作用
提供语义层能力，是很多“智能功能”的底座。

### 主要能力
- 主题向量生成
- 自动分类辅助
- 相似度计算
- 语义去重
- 结构匹配
- 品牌资料与参考资料召回
- 向量聚类与内链辅助

## 使用建议

- 只想先跑通基础写文，先配好 API、规则、主题、文章任务即可。
- 想提升质量，再逐步启用结构、参考资料、品牌资料和配图。
- 想做规模化和 SEO 运营，再补向量、聚类、关键词研究和 GSC。
