# 支撑模块总览

这一部分不是主生产链路的起点，但它决定 Yali AI Writer 能不能从“能写”走向“写得更稳、写得更像你的业务、写得更适合长期运营”。

如果核心模块解决的是：如何把规则变成主题，再把主题变成文章，那么支撑模块解决的就是：如何让文章拥有更好的图片、更多资料、更强品牌一致性、更可靠的结构与语义基础，以及更真实的搜索反馈闭环。

## 这些模块通常什么时候引入

最稳妥的顺序不是一开始全部配置，而是先跑通主链路，再按短板逐步接入。

- 当你需要图片落地时，引入图像 API 与自动配图
- 当你需要人工编辑协同时，引入编辑器 AI 助手
- 当你要让内容更像自己的品牌时，引入品牌资料
- 当你发现主题上下文太薄时，引入搜索物料
- 当你需要继续扩充词池时，引入关键词研究工具
- 当你追求更稳定的结构、召回和内链时，引入结构、向量与智能优化
- 当你需要让写作决策接入真实搜索反馈时，引入 GSC 数据洞察

## 这一层的核心认知

支撑模块不是为了“增加功能数量”，而是为了让系统在下面这些维度变得更成熟：

- 视觉完整度
- 资料密度
- 品牌一致性
- 结构稳定性
- 语义能力
- 搜索反馈闭环

所以阅读时，不要只问“这个页面能干什么”，还要问“它是在补哪一块短板”。

## 给 AI / 技术读者的结构化摘要

### purpose
Supporting modules strengthen the core writing pipeline through media, retrieval, brand context, semantic infrastructure, and post-publication analytics.

### timing
Introduce them after the core production flow is already running, then add them according to quality bottlenecks.

### module groups
- media: image api, auto images
- editorial assist: editor assistant
- business context: brand profiles
- retrieval: search materials
- upstream research: keyword research tool
- semantic/structure layer: structures, vectors, optimization
- feedback loop: GSC insights
